============================================================
BOT GOAL
============================================================

Build a production-grade Zerodha execution bot for SwingOS.

The bot should:

1. Read approved trade candidates from SwingOS engine signals.
2. Optionally receive engine webhook pushes for new actionable signals.
3. Validate signal freshness, score, verdict, execution levels, risk, and safety limits.
4. Ask the user for approval through Telegram inline buttons.
5. Optionally support email approval fallback later.
6. Place Zerodha orders only after approval.
7. Trade NSE equity swing setups only.
8. Use CNC product type only.
9. Support buy, partial exits, full exits, stop updates, and pyramiding winners.
10. Never average down by default.
11. Use limit order by default.
12. Use market order only if current price is within configured tolerance, default 0.5%.
13. Use GTT where supported for stop loss and targets.
14. Send all raw execution data back to the engine.
15. Maintain full audit logs.
16. Enforce all safety switches.
17. Support paper mode and live mode.
18. Be VPS-deployable.

POSITION SIZING
============================================================

Create:

backend/execution/position_sizing.py

Use:
- entry price
- stop loss
- bot capital limit
- max single trade risk %
- max capital per trade
- max capital per stock
- available cash/margins from existing Kite client
- current existing holdings/positions
- engine Layer 7 portfolio risk suggestion if available

Quantity calculation:

risk_per_share = intended_entry_price - stop_loss

max_risk_inr = bot_capital_limit_inr * max_single_trade_risk_percent / 100

quantity_by_risk = floor(max_risk_inr / risk_per_share)
quantity_by_capital = floor(max_capital_per_trade_inr / intended_entry_price)
quantity_by_stock_limit = floor(remaining_stock_allocation / intended_entry_price)

final_quantity = min(quantity_by_risk, quantity_by_capital, quantity_by_stock_limit)

Reject if:
- risk_per_share <= 0
- final_quantity <= 0
- required capital > available cash
- current exposure violates limits

Attach sizing explanation to approval request.

ORDER TYPE LOGIC
============================================================

Default: LIMIT order.

Limit price:
- For pullback entries: use entry_high or configured price inside entry zone.
- Do not place buy limit above configured max price.
- If current LTP is below or within entry zone, place limit order.
- If current LTP is above entry_high, only allow market/limit chase if within configured tolerance and signal is still fresh.

Market order rule:
- Market order is allowed only if:
  - config allow_market_orders = true

  - current LTP is within 0.5% of entry_high or trigger price
  - data is fresh
  - spread/volatility warning is not present
  - signal is not older than configured freshness window
  - market is open
  - safety switches clear

If price is outside tolerance:
- Do not place market order.
- Place limit order if reasonable, or reject and alert.

============================================================
EXIT MANAGEMENT USING SIGNAL VALIDITY MONITOR
============================================================

Integrate with existing Phase 2 Signal Validity Monitor.

Use latest signal_validity_checks recommendation:

HOLD:
- No exit.
- Continue monitoring.

WATCH_CLOSELY:
- Alert user.
- Do not exit automatically unless configured.

EXIT_EARLY:
- Request Telegram approval for full exit or partial exit.
- If config allows risk-reducing auto-exit, allow but default should request approval.

EXIT_NOW:
- Strong alert.
- If stop is hit or critical failure, exit can be configured as auto-risk-reduction.
- Default: require approval unless emergency_exit_auto_enabled.

BOOK_PARTIAL:
- Follow partial exit plan.
- Telegram approval optional by config.
- Default: alert and execute partial exit if already pre-approved by original plan.

TARGET_1_HIT:
- Sell T1 quantity.
- Move stop to breakeven if supported.
- Send feedback.

STOPPED_OUT:
- Exit remaining position or confirm stop/GTT triggered.
- Send feedback.
